# Bhakti Tank - Portfolio Website

A responsive portfolio website built for a web development assignment using:
- HTML
- CSS
- JavaScript

## Files
- `index.html` — semantic website structure
- `style.css` — styling and responsive design
- `script.js` — navigation, project message, contact form interaction

## GitHub Pages
1. Create a GitHub repository.
2. Upload all three files to the repository root.
3. Commit the files.
4. Go to Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and `/ (root)`.
7. Save.
8. Wait for GitHub Pages to publish the site.
